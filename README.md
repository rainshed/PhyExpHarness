# PhyExpHarness

PhyExpHarness 探索如何通过可复用的执行 Harness，让固定的 AI Solver 更可靠地完成科学实验任务。

我们希望让 Meta 模型自主开发、组合和测试执行插件，从实验结果中持续改进 Harness；让用户看懂每次尝试的变化、证据与取舍，并将选定成果带走，作为可独立运行、继续维护的项目。

项目以自主探索、受控执行和证据可追溯为基本原则。我们关注可复用的方法与跨任务的泛化，也保留失败和负结果，让改进建立在可核查的实验之上。
