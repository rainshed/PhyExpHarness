# 创建和运行活动

适用：当前新活动。旧活动继续使用自己的[冻结契约](../architecture/compatibility.md)。

## 创建与准备

选择主线 Solver、Meta、公开开发任务和目标，填写活动总运行时间与最高并发；轮次、实验总数可不单独设限。新活动不提供 token/费用总量和单题时限设置；任务时限由 benchmark 决定。初始 UI 默认值以[defaults.mjs](../../packages/meta-workbench-client/defaults.mjs)为准。

当前 Studio 表单仍要求“实验次数上限 ≥ 所选任务数”，不足时显示 H0 基线提示并阻止创建；这是尚未跟随后台 process 规则更新的前端限制。后台已允许更少的次数上限，运行时也不强制全套基线；通过 UI 创建时需满足现有校验或将次数设为不限。[待修复项](../plans/README.md#当前已确认的实现差距)保留这项差异。

未提交草稿保存在本版浏览器存储中。相同配置失败重试保留创建身份；创建结果未知时先刷新核对，不通过换键、重复点击或另建活动重试。配置改变会成为新请求。

创建后异步准备所选任务的固定 main/qsim/verifier 镜像、H0 候选及选中的参考环境。准备不调用真实模型、不开始活动计时、不消耗 Trial。H0 检查通过仅表示构建与入口成立，全部环境准备完成才可点击「启动进化」。

任务准备日志位于数据目录 `campaigns/<id>/checks/task-images.log`，候选构建日志在 checks 下。缺少 Quantum-Harbor 基础镜像、Docker 不可连接或源码身份变化会明确失败；不要用新标签冒充原镜像。固定环境的目的与限制见[执行架构](../architecture/execution.md)。

## 运行计划与实验

启动后 Meta 先提交并发和收尾时间计划，再自主提交候选批次。**新 process 活动不强制先测全部 H0，也不在首次提交计划时自动安排全套基线。** 对比是否充分应由实验依据说明。

一次受理的批次计一轮，任务数乘重复次数为计划尝试数；开始过的失败不会被清掉。查询、工程检查和失败的构建不计 Trial。平台不自动整次重跑失败实验，候选内部模型请求恢复由该候选策略决定。

运行详情显示计划版本、用户上限、实际并发和启动条件。新计划只在用户边界内生效，已受理/运行工作保留条件。单题阶段时限来自 benchmark，排队后剩余时间不足显示当前不可执行及所需时间，不能以缩短求解时间填满剩余活动时间。可撤回未启动项并保留原因。

## 版本选择与探索结束

Meta 显式选择、维持或回退通过检查的冻结候选，提交理由、相关证据、备选与局限。最新候选不自动获选；无评分候选也可以被有依据地选定，但不会因此获得平台效果认证。历史决定保留当时快照。

默认目标是持续改进固定 Solver 的执行 Harness；用户可以指定本次活动的目标。Meta 自主决定何时结束，并提交结束理由和本次实验总结。无需预设稳定性规则，也不要求达到某个成绩、选定候选或补齐每轮/最终分析报告。

受理后停止新增实验、取消未启动项，已启动的工作在原有时间约定内结束并归集，随后活动显示「已结束」。概览和报告展示 Meta 的收尾理由与总结；结束状态不代表平台认证目标达成。Meta 未能提交总结时如实显示缺失，系统事实摘要不会替它编写结论。既有活动仍按原冻结规则运行，升级源码不会自动改写其收尾规则。

## 暂停、恢复与停止

| 操作 | 实际行为 |
|---|---|
| 暂停新工作 | 中断当前 Meta，停止新实验启动；已运行实验继续，墙钟继续 |
| 恢复 | 核对已有工作、镜像和冻结资产，再按原活动状态续接 |
| 停止并收尾 | 取消未启动项并终止正在执行的实验，剩余时间可用于分析已有证据 |
| 关闭页面/退出 UI 宿主 | 后台继续运行 |
| 调整用户上限 | 由用户操作；已消耗次数不重置，运行任务不自动延期，结束活动不复活 |

strict 截止终止剩余工作；drain 只允许已启动任务在明确额外期限内结束。Meta 不可用时保留系统事实并标注分析未完成。模型访问不依靠 token 余额判断，仍受身份、时间、取消和存储边界约束。

启动、恢复或删除请求可能需要较长检查，UI 对这些控制操作等待最多 120 秒，普通读取通常为 20 秒。超时不取消后台操作；出现“结果尚未确认”先刷新核对，沿用原请求身份。

Meta 可以通过工作台向用户提问，已保存问题和回答由后台持久管理；关闭页面不会删除问题。仅主 Meta 可发起，回答由用户身份提交。

## 参考实验

创建时分别启用参考模型/参考 Harness，可多选允许项，选择 Meta 自主配对或用户指定配对。仅模型插件改变模型，仅 Harness 插件沿用固定 Solver，两者都启用才允许联合组合。参考模型来自原生 Models，不从主线供应商目录自动补齐。

在「运行详情 → 参考实验」可停用/恢复创建时允许项，不能新增未冻结内容。默认停用等待运行项结束，显式同时停止才终止它们；恢复不会清零次数或重启已取消实验。

参考结果独立保存，不能提高主线成功率。兼容矩阵中的支持表示配置/协议可接入，不表示真实服务已探测通过；不可用组合保留原因，不静默换模型。详见[参考实验架构](../architecture/references.md)。

阅读结果见[证据与报告](evidence-and-reports.md)，交付见[导出指南](export.md)，永久删除见[维护指南](maintenance.md#永久删除一次活动)。
