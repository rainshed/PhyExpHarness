# 证据、报告与本地存储

状态：当前实现；用户阅读见[证据与报告](../guides/evidence-and-reports.md)，维护步骤见[维护指南](../guides/maintenance.md)。

## 官方评分与任务完成分

[结果收集](../../src/control/result_collection.py)核验官方结果归属及内容；[outcomes.py](../../src/evidence/outcomes.py)是任务完成统计唯一入口。官方 score/officialReward 缺失保持 null，不能因派生失败而伪造官方零分。

新活动默认 task-completion-v4，按以下顺序判断：

| 条件 | 处理 |
|---|---|
| 排队、启动或运行中 | 待定，不提前结算 |
| 已结束且有可信官方二元结果 | 1 成功，0 失败；后续清理故障不覆盖 |
| 尚未核实结束 | 待核实 |
| 确认未进入启动尝试且无官方结果 | 未执行，不进入分母 |
| 明确 user_stop，且无已确认先行失败 | 人工取消，不进入分母 |
| 其他已启动并最终结束的尝试 | 失败、派生 0、进入分母，保留原因 |

startedAt 表示进入启动尝试，不要求已经取得模型响应。unknown 带结束确认计失败，没有结束确认仍待定；仍在归集不因缺分提前结算。request_cancelled 本身不证明人工撤销。官方有效结果优先于不完整启动元数据。

逐任务成功率为官方通过次数除以纳入的已结束尝试数，跨任务等权；完全没有纳入尝试的任务保持未测/待定。旧规则及缺省 v1 的读取见[兼容规则](compatibility.md)。

## 不可变原件、索引与报告

原件按 SHA-256 保存在 `artifacts/sha256/`；原始路径、归档清单、大小、摘要与证据 ID 分别保留。同正文的不同来源不能因去重丢失路径；访问仍按活动授权。

生产者退出且归集达到相应阶段后，后台将原路径转为同文件系统硬链接视图，共享不可变正文。发布使用临时文件、校验和原子替换，不允许原地编辑共享对象。归集工作与完整索引分阶段持久化，可信评分与索引完整性分别展示，见[控制后台](control.md#数据库归集与恢复)。

查询使用一致读快照；query-tree-v1 将对象字段、列表分片和大值存成可复用文件。报告保存当时不可变事实引用与 Meta 分析修订，数据库列表只读元数据，详情核验正文摘要；旧内嵌事实仍可读。后续结果不会悄悄改写旧分析或选择。

[research.py](../../src/control/research.py)保存动机、观察、转折、补充说明及来源关系。证据片段绑定原件摘要和准确范围；跨活动纳入由用户显式授权，默认仅用户阅读，授权 Meta 后才成为目标活动材料。历史成绩不进入目标主线统计。

## 日志与容量

受管 RPC、审计与输出日志分段 gzip 压缩，`<日志名>.segments/index.json` 记录关闭段，原日志名是尾段；完整历史须按索引逐段读。原生会话恢复文件不按普通日志轮转。读取器、回放与证据接口支持分段，不应以直接读尾段宣称读完所有历史。

[storage.py](../../src/control/storage.py)管理 storage-policy.json、容量缓存和后台巡检。当前默认数据上限 40 GiB、活动 20 GiB、启动空闲保护线 10 GiB、紧急水位 2 GiB；准确字段及其余默认值以 DEFAULTS 和存储 API 为准。用户可修改策略，Meta 无权提高上限。

空间不足阻止新生产者并等待，墙钟继续；紧急水位停止在途生产者，保留部分输出与根因。storage_capacity、log_size_limit、log_record_size_limit、storage_write_error 分别表示容量、显式输出额度、单条大小和写入故障，退出时的取消不覆盖先行错误。任意工作区写入没有 OS 硬配额，快速增长或其他进程占盘可能先于巡检耗尽空间。

GC 仅回收可证明无引用、超过宽限期的对象/临时文件及符合锁和进程条件的旧缓存代际。当前依赖、冻结镜像、会话和研究证据不按年龄或分数删除；无法确认使用状态则跳过。不自动清理容器镜像。

## 永久删除

[deletion.py](../../src/control/deletion.py)协调用户授权的单活动删除。GET `/campaigns/{id}/deletion` 预检查；POST 携 expectedRevision/idempotencyKey 受理，失败重试需 retry=true 和新键。Meta 无此权限。

先建立删除屏障、撤销租约、停止所属 Meta/研究/实验/归集，等待构建、导出及已准入响应结束，再按持久清单清理。共享对象逐传递引用判断，v3 源码、产物及含候选内容的构建缓存均覆盖。清理分批进行，不以隐藏活动代替成功；重启续做，失败保留原因。

其他活动已纳入其证据/报告时阻止删除；混合备份、越界路径、未知硬链接或无法确认的所有权也会阻止。公共依赖、任务/Runner 镜像、供应商凭据和外部下载/备份不随之删除。成功后只留防重所需最小身份，不承诺介质取证级擦除。

验证：[v4 计分](../../tests/unit/task_completion_v4_test.py)、[研究记录](../../tests/unit/evolution_test.py)、[内容对象](../../tests/unit/artifact_objects_test.py)、[查询快照](../../tests/unit/storage_snapshots_test.py)、[容量](../../tests/unit/storage_capacity_test.py)、[删除](../../tests/unit/campaign_deletion_test.py)。

插件库拥有独立源码对象及删除记录，不属于来源活动的运行历史清理范围。活动删除不会连带释放库版本；已删除版本仍被活动 H0 或其他库插件依赖时继续保留。发布/引用/回收共用受管锁；具体索引、恢复与身份见[独立插件库](versions-and-export.md#独立插件库)。
