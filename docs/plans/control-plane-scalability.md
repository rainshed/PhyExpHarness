# 长活动控制面与证据规模修复

日期：2026-10-25。状态：实施中；用户已授权先更新文档、实施、验证并同步 TensorTrain 2。

## 依据与边界

只读审计活动 `campaign-531d779a-88ed-427c-94ad-bf752fba7584`：73 次实验结束，1 次 CNOT 未启动；两次 CZ 产生 24,922、14,060 条证据，官方结果到完成事件分别延迟约 108、238 分钟。证据入库在写事务内逐条扫描整个活动，归集阻塞同一调度循环；报告重复嵌入大证据目录。已完成同任务的比较上下文一致，未启动记录造成笼统可比性警告；两种源码摘要范围不同，不能直接比较。

固定 Solver、原 benchmark 时限、用户限额、官方评分和 task-completion-v4 不变。Meta 保留实验安排、版本选择和恢复策略所有权。不重跑历史实验，不改写冻结候选、Meta 协议和原始证据，不把后台归档失败伪装为科学失败。复用 SQLite、不可变内容存储和现有文件阅读协议。

## 1. 执行、结果和归档分离

控制循环仅检测完成标记、监督进程、受理持久工作、调度及恢复，不同步遍历完整证据。独立工作进程处理结果核验与索引；工作身份绑定 Trial、归档身份与阶段，使用执行租约、幂等提交和可恢复进度。

已确认执行及清理结束即释放执行名额；官方结果仍须核验准确任务、候选、评分、提交及归档来源。结果明确前保持归集中；可信评分可用后独立发布，证据索引继续后台完成。确定无官方结果的终结尝试仍依 v4 计失败，不以无限待定规避计分。

分别记录实际执行结束、结果可用和证据索引完成时间。完整证据未发布时显示归档中、进度或错误，不声称完整。结果验证失败有独立诊断；归档失败不覆盖已验证评分。旧记录缺少阶段时间时显示未知，不倒写历史。

## 2. 有界事务与读取

证据查重使用活动、Trial、类型、摘要的索引，查询在 SQL 中完成。相同正文共享，原路径来源引用不能因正文相同而消失。哈希、文件写入及对象发布在数据库事务外；短事务只检查活动可写和登记元数据。发布与 GC 协调，未登记对象不得在提交窗口被回收。

归档索引分批提交，重启只补未完成项。状态、证据、报告查询不能先加载全部正文再分页。报告保存完整不可变事实清单的引用，读取兼容旧内嵌事实；冻结快照不得指向可变最新目录。原始正文与旧证据 ID 保持可读取。

容量巡检在后台进行，调度与界面使用带 observedAt 的缓存统计和即时磁盘可用量；不在查询中扫描目录。积压不表示允许无限生产，继续遵守既有容量保护。

## 3. 调度与诊断

未启动任务保持未执行语义，细分正常排队与当前条件无法启动。受理前检查当前时间可行性，启动前复核；提供 requiredSeconds、最新 availableSeconds、latestStartAt 和阻塞原因。支持撤回未启动项，保存原因与事件；不缩短 benchmark 时间，不替 Meta 选择实验。目标覆盖以同一候选、逐任务所有尝试为基础。

比较诊断分别表达尚未执行、元数据缺失、字段实际差异；提供涉及的 Trial 和字段。摘要记录版本与范围；process 契约不要求旧隔离 Runner 身份。批次报告的比较限制使用准确事实范围，不能被无关在途记录污染。

官方结果、外部执行诊断、候选上报错误并存。错误保留 code、message、阶段、来源和证据位置；候选诊断不成为评分权威，不让平台接管候选重试策略。

## 4. 停止、删除、恢复和交付

归档工作持久化，服务重启恢复未完成工作，不重跑 Solver。活动停止/结束不丢弃已有数据。删除先撤销所属后台任务并等待退出，再移除活动数据；其他活动请求不因全局清理而失败。GC 保护工作引用、报告快照、证据和已发布会话路径。

最终报告和导出明确证据完整性；后续补齐生成新修订，不改变旧快照。维护备份位于 data 外的私有目录。独立发布目录准备与检查后，在无在途工作时切换服务；冻结资产不替换。

## 5. 实施单元和验收

1. 文档先行并本地提交。
2. 持久归集工作、索引与短事务、阶段状态及恢复/删除协调；相关验证后独立提交。
3. 查询与报告规模优化、容量缓存；相关验证后独立提交。
4. 调度反馈、比较和错误诊断、工作台展示；相关验证后独立提交。
5. 综合规模/故障验证、更新运行说明，发布到 TensorTrain 2。

必须覆盖至少 50,000 份证据和 15 路并发操作；慢归档不阻塞调度、停止和 Meta 恢复；工作进程在发布、登记、进度更新窗口中断后幂等恢复；归档期间删除一活动不影响其他活动；旧报告、证据、官方结果、冻结内容可核验。记录实际响应时间、锁等待、吞吐和内存，不以小夹具替代规模证据。真实模型不用于替代工程验证。

实施记录与命令输出放在 `reports/development/meta-harness/control-plane-scalability/`（不入库）；本文件及运行说明记录完成范围与剩余限制。
