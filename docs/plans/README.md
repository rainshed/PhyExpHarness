## 当前已确认的实现差距

**独立插件库与用户组合 H0 已实现，工程与人类验收分别登记。** [任务书](plugin-library-and-h0.md)保留自动证据、待人类验收清单和验收入口；当前操作见[插件库指南](../guides/plugin-library.md)。Meta 全库读取及自主选择 H0 留待后续独立插件。

**Agent 安装与首次实验仍有外部验证缺口。** 安装、自检、统一启动、活动命令、CI 配置和本地干净源码检查已完成，当前用法见[Agent 安装流程](../guides/agent-installation.md)。托管 CI、其他平台容器、真实首次实验和浏览器验收仍按[实施计划](agent-installation.md)分别记录。

新 process 活动表单已允许多任务但较少实验次数，仍保留并发与额度合法性约束。未知创建请求沿用原键和原参数；此项随用户 H0 接入完成。

## 仍需单独安排的验证

| 项目 | 当前已知边界 | 完成依据 |
|---|---|---|
| 数日活动与容量压力 | 已有容量、分段、规模及恢复机制；本轮工程测试不覆盖数日真实运行 | 明确环境/任务/停止条件，保留持续运行、低空间及恢复记录 |
| 复杂并发恢复窗口 | 普通委派、通知和归集有持久化/契约；不承诺未落盘消息恰好一次 | 针对遗漏窗口的故障注入与副作用核对 |
| 每种供应商真实服务 | 目录与协议适配不等于所有端点、认证和模型已在线通过 | 在授权范围内执行连接/工具回环并记录准确配置 |
| 每份导出的真实独立运行 | 导出默认只完成静态校验，不能继承另一份包的验收状态 | 对准确包与运行环境完成搬迁和真实执行，记录原仓库可访问性 |
| 科学效果、泛化与 Meta 组合消融 | 当前提供冻结、记录和比较基础，不提供自动因果认证或完整消融研究结论 | 单独设计可比较的重复/消融研究，保存失败与不确定性 |
| UI 人工阅读与长内容体验 | 有页面与宿主契约；本轮文档核对不替代浏览器/用户体验验收 | 基于实际页面的完整操作、长内容和窄屏检查 |

这些条目区分验证范围与缺失功能，不把“未在本轮运行”误写成“代码尚未实现”。需要新增功能时另建聚焦计划，列出产品依据、实现范围、验收条件和剩余事项。
