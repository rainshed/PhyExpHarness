# 单次进化活动永久删除

日期：2026-10-23 · 状态：已实现，合成数据与无模型容器验收通过。使用方法见[运行说明](../operations/meta-harness.md#单次活动永久删除)。

## 1. 产品行为与授权

用户可以永久删除一次 Campaign 及其所属历史。操作仅由工作台用户身份发起，Meta、Solver、研究子会话和审查者无此权限。此操作是用户明确授权的历史移除，区别于日常运行和版本整理中必须保留原始证据的要求。

活动详情提供删除入口。确认前显示名称、实验数、报告数和阻止删除的依赖；有在途工作时按钮为“停止并永久删除”，否则为“永久删除”。一次确认提交后台任务；页面显示停止、清理、失败重试及完成，关闭页面不取消任务。失败的活动继续可见，不能以隐藏活动代替删除成功。删除完成清空该活动的页面选择和查询缓存。

## 2. 所有权与清理边界

删除活动配置、候选、主线/参考批次和实验、会话/研究子会话/停止审查、用量/准入/租约、问题、研究记录/来源引用/选择决定、事件、命令回执、报告全部修订、导出及验收记录；同时清理工作区、材料、轨迹、请求审计、监督日志、恢复记录和对应文件。

共享证据、执行组合及插件对象、Meta 组合及对象、资料包和包含活动内容的物化缓存按剩余引用判断：仍被其他活动或执行者使用则保留，无其他引用才回收。回收须遍历组合的传递引用，兼容旧 Bundle、硬链接整理对象和物化副本；只清理本次活动关联的对象，不顺便清空无关目录。公共依赖安装、任务/Runner 镜像、供应商配置和凭据不属于活动历史，继续保留。

其他活动通过历史来源功能显式纳入本活动证据/报告时，第一版阻止删除并列出目标活动与材料。核查覆盖用户阅读副本和 Meta 授权副本，受理事务内再次检查，受理后不能新增来源引用。不得静默保留跨活动历史副本后宣称全部删除，也不得自动修改其他活动的研究依据。

程序管理的历史整理备份、混合快照或未知布局如果无法安全区分所有权，应在预检查时阻止删除，给出具体路径/原因，不扩大删除范围。用户另行复制、下载的项目和外部备份不随本功能删除；本功能不承诺存储介质取证级擦除。

## 3. 执行与恢复

1. 预检查枚举记录、文件、共享引用和阻塞项，返回当前活动修订。正式提交再次核查修订与依赖。
2. 原子记录独立删除任务并建立写入屏障。禁止启动/恢复、调度、Meta 恢复、实验、导出、新引用及迟到回调写入；作废运行租约。删除流程不启动总结模型或生成新报告。
3. 停止所属进程、研究及审查 Runner、主线和参考实验，等待后台构建/导出及已进入的请求结束，清理所属容器和卷。不能仅凭活动终态或保存的 PID 判定已停止；重启后必须核对进程身份。
4. 在清理互斥区生成持久清单，核对所有路径位于受管根目录且不经符号链接越界；文件与数据库不能视为一个原子事务。清单先落盘，再逐项清理，最后事务删除活动及所有附属记录。共享对象回收与新引用/物化互斥。
5. 全部清理成功才显示完成；失败保留阶段和错误，可重试。后台重启继续未完成任务，已不存在文件视为已完成。完成后清除含历史内容的清单/回执，仅保留活动 ID 和旧创建请求摘要等最小防重标记，防止迟到写入和重放创建复活活动。

创建回执目前存于 `commands` 的全局作用域，须清除其中活动配置和结果正文；不能只执行 `WHERE campaign = ?`。删除任务独立于活动表，不能随级联清理丢失恢复依据。共享诊断及显示注释中的活动关联条目也须处理，无法可靠分离时报告阻塞。

## 4. 分层与接口

`src/control/` 持有删除协调器、持久任务、运行停止及存储清理；Store 提供事务屏障与防重。执行侧保持独立，不反向依赖控制服务。公共工作台客户端提供预检查、提交、进度与重试，Studio 实现确认对话框及状态提示，桥接沿用现有用户身份与 POST 命令。

采用 `GET /campaigns/{id}/deletion`、`POST /campaigns/{id}/deletion`，首次提交携带 `expectedRevision` 和 `idempotencyKey`。未受理时 GET 返回预检查，受理后返回持久任务状态；重复请求返回同一任务。失败重试携带 `retry: true` 和新的 `idempotencyKey`。删除后任务入口仍可查询最小完成状态，普通活动及其对象接口不可继续读取历史。

数据库版本 6 新增 `owned_artifacts`、`deletions` 和 `deleted_create_keys`。构建发布、报告及导出在写入正文前登记所属路径，构建暂存目录同样登记，以覆盖进程突然退出。清理等待完整 HTTP 响应（包括导出下载）及已准入的后台操作退出；删除受理与调度共用互斥锁，清理与历史整理、正文对象回收共用已有存储锁。`artifacts/sha256/` 正文按活动目录与 Trial 归档的硬链接引用核对，无法解释的剩余硬链接会阻止清理完成。

## 5. 验收

- 合成活动覆盖全部表、全局创建回执、主线/参考实验、报告修订、导出检查及历史恢复文件，删除后不可查询，文件无所属残留。
- 两活动共享插件/证据/Meta 对象与缓存时，剩余活动仍可读取、解析和导出；最后引用删除后回收专属内容。
- 跨活动纳入、混合备份、越界路径、符号链接和无法确认的进程/容器均不误删；仅用户可发起。
- 停止在途工作、构建/导出等待、迟到回调、重复提交、旧创建重放、部分文件删除失败及后台重启可复现，无记录复活或假成功。
- 工作台确认/取消、运行中删除、失败重试、刷新恢复、完成返回列表和窄屏可用；采用隔离合成数据，不删除真实活动、不调用真实模型。
